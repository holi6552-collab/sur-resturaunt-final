## Part 2 - HTML Draft Progress

For Part 2, I created the HTML structure for all four pages of my SUR Restaurant and Lounge website. These pages include the homepage, about page, menu page, and contact page.

I added restaurant information, menu items, images, and links to help visitors navigate the website. I also organized my photos into an images folder and added alt text for accessibility.

For this part of the project, I focused on using proper HTML elements and keeping everything organized. I haven't added CSS yet because I'll do that in Part 3.

## Part 3 - CSS Styling & JavaScript

For Part 3, I added CSS to improve my website's appearance. I also used my original color palette of burgundy, cream, gold, and charcoal. I also used Playfair Display for headings and Lato for the regular text.

I styled the buttons, images, navigation, and different sections to make everything look more professional and consistent across all four pages. 

I also made the website responsive so it adjusts to different screen sizes. On mobile screens, the content stacks into one column. On tablets, some sections use two columns, and on desktop, the website has a wider layout with multiple columns. 

I was only able to find professional pictures of the interior design, so I wasn't able to add pictures of the food like I originally planned. 

For JavaScript, I added a hamburger menu for mobile navigation. The menu allows users to open and close the navigation links, and the icon changes when the menu is opened.
